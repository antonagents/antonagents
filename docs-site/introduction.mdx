**Antonagents** is a self-hostable, multi-tenant platform for building AI agents
that don't just chat, they **act**: they run on a schedule, use your team's tools,
query your data, and deliver finished work. Everything runs on infrastructure you
control, so your data never has to leave it.

## How it fits together

An **agent** is a reusable configuration, a name, an instruction, the tools and
data it can use, and optionally a schedule. Each time it runs (a chat message, a
manual trigger, or a scheduled fire) is a **run**, executed inside an isolated
container.

```
Org (your team)
 └─ Agent  ── instruction + connectors + skills + data sources
      ├─ Chat run      (you message it)
      ├─ Manual run    (you hit "Run")
      └─ Scheduled run (a routine fires on cron/interval)
           └─ each run executes in a sandboxed container → events + artifacts
```
