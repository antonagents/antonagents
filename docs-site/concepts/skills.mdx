---
title: "Skills"
description: "Reusable instruction packs that sharpen how an agent works."
---

A **skill** is a reusable pack of instructions you can attach to an agent to give
it a specific capability or house style, without rewriting the agent's prompt
every time.

Think of a skill as expertise on tap: a way of formatting reports, a design
system for generated pages, a domain checklist, or a standard operating
procedure. Attach it to any agent that should follow it.

## Using skills

- Skills live at the **org** level, so everyone on your team can reuse them.
- Attach one or more skills to an agent when you build it.
- At run time, the skill's instructions are made available to the agent so it
  follows them consistently.

## Built-in skills

Every org starts with at least one built-in skill (for example, **Artifact
Design**, which guides how the agent builds polished HTML pages and reports). You
can add your own alongside it.

<Tip>
  Skills pair well with routines: encode "how we always do this" once as a skill,
  then every scheduled run applies it automatically.
</Tip>
